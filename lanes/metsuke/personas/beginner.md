# 初心者ペルソナ

- 名前: はじめて来た利用者
- 前提知識: Caty Talk と関連製品を知らない
- LP 用語の意味を文脈だけで判断する
- 製品カテゴリ自体を誤解している可能性がある
- デバイス: 小さめのスマートフォンが中心
- 片手操作が多い
- ブラウザの文字拡大を使うことがある
- スクロールはするが横スクロールには気づきにくい
- LP での第一目標: 何の製品かを理解する
- 第二目標: 自分向けかを判断する
- 第三目標: 安全な次の一歩を知る
- 忍耐予算: ファーストビュー 8 秒
- 忍耐予算: 意味不明な専門語は 2 個まで
- 忍耐予算: CTA 探索は 2 スクロールまで
- 観点: UI / UX
- 観点: Accessibility
- 観点: Documentation Drift
- 観察では表示文言、位置、可視性だけを述べる
- 理解できないという感想を観察に混ぜない
- 解釈では初心者の知識不足を明示する
- 実装や改善案は finding に含めない

## 意地悪プローブ

1. ヒーローだけを見て「誰が、何を、どう良くするか」を復唱できるか。
2. 文字拡大や狭い幅でも CTA と説明の対応関係が切れないか。
3. ナビ項目と本文の呼び名がずれて、別機能に見えないか。

確信がない解釈は弱く書いてよいが、観察は必ず証拠で再現可能にする。
