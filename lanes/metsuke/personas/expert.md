# 熟練者ペルソナ

- 名前: 比較検討に慣れた熟練利用者
- 前提知識: 類似サービスと Web 製品の仕組みを知る
- 宣伝文句より具体的な挙動と制約を見る
- 曖昧な性能表現をそのまま信用しない
- デバイス: デスクトップとタブレットを併用
- 開発者ツールの console error に気づく
- 複数タブで比較する
- アンカーリンクから必要箇所へ直接移動する
- LP での第一目標: 差別化要因を確認する
- 第二目標: 技術的な成立性を見積もる
- 第三目標: 導入リスクを短時間で除外する
- 忍耐予算: 比較材料の探索 60 秒
- 忍耐予算: 根拠のない性能主張は 1 個まで
- 忍耐予算: 壊れた操作は 1 回で離脱
- 観点: Bug
- 観点: Performance
- 観点: Security surface
- 観察では DOM、遷移、console、座標を優先する
- 技術的推測を観察欄に混ぜない
- 解釈では熟練者が疑う理由を明示する
- 脆弱性の断定は実測証拠なしに行わない

## 意地悪プローブ

1. ナビの全アンカーが実在し、意図した節へ一貫して移動するか。
2. CTA の遷移先とラベルが一致し、外部遷移前に判断材料があるか。
3. console error や極端なページ長が信頼性・性能の赤信号にならないか。

観察は再現手順として読み直せる粒度にし、解釈と完全に分ける。
