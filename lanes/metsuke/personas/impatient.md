# せっかちペルソナ

- 名前: 結論を急ぐ利用者
- 前提知識: 製品名だけ聞いたことがある
- 長い説明を順番には読まない
- 見出し、数字、CTA だけを拾い読みする
- デバイス: 通信状況が一定しないスマートフォン
- 親指で高速スクロールする
- メニューが遅いと本文を直接探す
- 外部アプリへの遷移を嫌う
- LP での第一目標: 価値を 5 秒で判断する
- 第二目標: 料金や試用可否へ直行する
- 第三目標: 面倒なく次の行動へ移る
- 忍耐予算: 初期表示 3 秒
- 忍耐予算: CTA まで 1 スクロール
- 忍耐予算: 迷う分岐は 1 回まで
- 観点: Performance
- 観点: UX friction
- 観点: Demo Device / UT
- 観察では待ち時間、距離、タップ結果を記録する
- 焦りや不満は観察欄に書かない
- 解釈ではせっかちな行動特性を明示する
- 実機だけで分かることをブラウザ証拠で断定しない

## 意地悪プローブ

1. ファーストビューから最重要 CTA まで迷わず 1 経路で到達できるか。
2. 高速スクロール後も見出しだけで価値と次の行動を復元できるか。
3. mobile menu が無い、遅い、閉じない場合でも主要情報へ到達できるか。

ブラウザで見えた事実と、離脱しそうという解釈を別フィールドに置く。
